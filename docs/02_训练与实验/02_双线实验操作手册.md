## 2. 固定环境与脚本

### 2.1 资源检查
正式训练前固定先跑：

```bash
python ./script/check_project_resources.py \
  --check_checkpoint_load \
  --sample_limit 2

python ./script/check_cecsl_dataset.py \
  --check_pose_content
```

当前资源检查规则：

1. `mt5 / checkpoint / labels / dev / test` 必须正常
2. `dev / test` 不能缺样本
3. `train` 如果只是极少量缺失，可继续训练，但要记录

### 2.2 固定脚本
1. 训练：`local_sign_tools/finetune_cecsl_rgb_support.py`
2. 评估：`script/eval_cecsl_samples.py`
3. 指标汇总：`script/compute_cecsl_text_metrics.py`

### 2.3 当前推荐训练底座

```bash
python ./local_sign_tools/finetune_cecsl_rgb_support.py \
  --checkpoint ./out/cecsl_rgb_support_round6_overnight_20260407/best_checkpoint.pth \
  --output_dir ./out/EXPERIMENT_NAME \
  --device cuda \
  --dtype bf16 \
  --stage1_epochs 0 \
  --stage2_epochs 2 \
  --batch_size 1 \
  --num_workers 8 \
  --stage2_lr 1e-7 \
  --stage2_mt5_lr_scale 0.1 \
  --weight_decay 1e-4 \
  --gradient_accumulation_steps 4 \
  --max_length 256 \
  --eval_split dev \
  --selection_split dev \
  --selection_sample_count 50 \
  --selection_sample_mode random \
  --selection_seed 42
```

在这个底座上切三种主模型：

1. `--no_rgb_support`：`pose-only`
2. `--rgb_support --train_rgb_frame_sampling confidence_topk --eval_rgb_frame_sampling confidence_topk`：`naive RGB`
3. `--rgb_support ... --fusion_use_uncertainty_gate --fusion_meta_dim 3`：`full model`

## 6. 句型切片正式表

### 6.1 这组实验的定位
这一步不优先再跑新训练，而是优先把已有结果组织成正式表。

优先类别：

1. `长句 / 短句`
2. `时间表达`
3. `问句`
4. `否定`
5. `数字`

目标：

1. 回答 `RGB 何时有用`
2. 回答 `reliability-aware 在哪些句型上更值得保留`
3. 为论文 Discussion 提供正式表格证据

### 6.2 操作要求
优先复用已有主模型结果，不新开训练。

建议主比较组固定为：

1. `ablation_pose_only`
2. `ablation_rgb_support`
3. `ablation_uncert_gate`

必要时可补：

4. `ablation_gate_no_meta`

### 6.3 输出物
至少产出：

1. 一张句型切片正式表
2. 每个类别的样本数说明
3. 一句总结：哪些类别 RGB 帮忙，哪些类别 pose 更稳

### 6.4 进入论文正文的条件
1. 切片规则稳定
2. 各类别样本数清楚
3. 结论不是零散举例，而是正式表格

### 6.5 现在直接用哪些结果做
优先固定这三组：

1. `ablation_pose_only`
2. `ablation_rgb_support`
3. `ablation_uncert_gate`

如需补一句机制说明，可在附表里加：

4. `ablation_gate_no_meta`

正式整理时优先用 `test100_eval.csv`，`dev100_eval.csv` 只作辅助核对。

### 6.6 按哪些类别切
当前统一按下面五类切，不再扩散：

1. `长句 / 短句`
2. `时间表达`
3. `问句`
4. `否定`
5. `数字`

推荐最简判断口径：

1. `长句 / 短句`
   - 短句：参考文本长度较短
   - 长句：参考文本长度较长
2. `时间表达`
   - 含明显时间词、日期、年份、时段
3. `问句`
   - 含问句标记、疑问词
4. `否定`
   - 含“不 / 没 / 无 / 不能 / 不会”等
5. `数字`
   - 含阿拉伯数字或中文数字表达
