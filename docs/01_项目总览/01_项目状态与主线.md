## 项目到底在做什么

这个项目基于 `Uni-Sign` 做低资源 `CE-CSL` 中文连续手语翻译研究，核心问题不是简单“加 RGB”，而是：

`在低资源场景下，RGB 什么时候真的可信、什么时候会引入噪声。`

## 项目主线怎么演化

### 阶段 1：Uni-Sign 到 CE-CSL 适配

做了：

1. 理解 `Uni-Sign` 的 backbone、训练链路和数据流。
2. 完成 `CE-CSL` 数据适配。
3. 跑通 `pose-only + SLT` 主链路。

### 阶段 2：RGB-support 引入

做了：

1. 引入 hand-centric RGB support。
2. 接入 `EfficientNet-B0` 本地权重。
3. 打通 RGB 与 pose 的融合链路。

### 阶段 3：主模型确认与受控实验

围绕这些模型做对照：

- `round6_best`
- `best_loss`
- `round7_short_refine`

同时做了：

- `stage2_epochs = 2 / 4`
- `stage2_mt5_lr_scale = 0.02 / 0.05 / 0.1`

### 阶段 4：论文级 ablation 与新模块

完成了：

1. `confidence_topk vs confidence_weighted`
2. `single-stage vs two-stage`
3. `pose-only vs RGB-support`
4. `uncertainty-aware RGB-pose fusion gate`

## 当前最重要的判断

1. `ablation_pose_only` 仍然是强对照。
2. `ablation_uncert_gate` 是当前新的 RGB-support 主候选。
3. 当前不能写成“RGB-support 已全面超过 pose-only”。
4. 当前最有价值的主线不是“继续开新模型”，而是 `reliability-aware multimodal fusion`。
